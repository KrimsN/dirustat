Заверши текущую задачу:

1. `cargo fmt --all` → `cargo xtask ci`. Если что-то красное — исправь причину, не отключай правила и не ослабляй lints.
2. Если добавлены/изменены команды — прогони `hostile_params_never_panic` (когда он есть) и проверь чеклист «добавить команду» из `docs/contributing.md`.
3. Если менялся горячий путь — сделай замер (`docs/performance.md`) и запиши числа.
4. Если менялся UI — сними скриншот и посмотри его.
5. Обнови документы прогресса по `docs/progress-docs.md`: `docs/gaps.md`, `docs/target-app-parity.md`, `ROADMAP.md` (числа должны совпасть), `docs/roadmap.md`.
6. Допиши запись в `log/devlog.md` (что вошло, числа, проверено, Still open).
7. Перезапиши `plan/STATUS.md`.
8. Сделай коммит: короткое английское сообщение с id задачи (`M1.2: …`).
9. Сообщи пользователю по-русски: что сделано, что проверено, что осталось.
