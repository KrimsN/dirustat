# Дополнения для Claude Code

- Начало сессии: прочитай `plan/STATUS.md`, затем возьми задачу из `docs/gaps.md`. Слэш-команды проекта: `/start-session`, `/finish-task`, `/add-command`, `/perf-check` (`.claude/commands/`).
- Субагенты проекта (`.claude/agents/`): `rust-implementer` (реализация в рамках одного крейта), `never-crash-reviewer` (ревью на паники/враждебные входы), `parity-tracker` (обновление паритетных документов).
- Не останавливайся с вопросами, если решение не относится к разделу 7 в `AGENTS.md`.
- Перед ответом пользователю сверяй язык: русский для общения/доков/комментариев, английский для кода и коммитов.
- Деструктивные операции на реальных данных пользователя запрещены (`docs/safety.md`).
