# Безопасность данных пользователя

> Статус: 2026-10-13 · ревизия 1. Обязательно для людей и агентов.

## Принципы

1. **Скан = только чтение.** Ни одна команда сканирования, статистики, поиска и экспорта не изменяет файлы пользователя. Экспорт пишет только в явно указанный путь.
2. **Деструктивные команды** (`file.delete`, `file.move`, `cleanup.run`) требуют:
   - параметр `confirm: true` (без него — `Err(ConfirmationRequired)` и описание того, что будет сделано);
   - `dry_run: true` возвращает список затронутых путей и размер, ничего не меняя;
   - по умолчанию — **в корзину** (Windows Recycle Bin / `trash` на других ОС); безвозвратное удаление — отдельная команда `file.delete_permanent` с собственным подтверждением и предупреждением в UI;
   - отказ для защищённых путей: корень тома, `Windows`, `Program Files`, `ProgramData`, профиль пользователя целиком, системные тома при обходе reparse point.
3. **Проверка перед действием.** Перед удалением путь перепроверяется (существует, тот же file id, что в дереве; не вышел за пределы корня скана). Устаревшее дерево не должно приводить к удалению не того.
4. **Журнал.** Каждое деструктивное действие пишется в журнал сессии (путь, размер, время, режим) — для отката из корзины и для отладки.

## Правила для агентов

- **Запрещено** запускать деструктивные команды на реальных каталогах пользователя (`C:\Users\…`, `Documents`, `Desktop`, внешние диски). Тестируй только на каталогах, созданных тестом во временной папке (`tempfile`) или фикстурами `cargo xtask fixtures`.
- Скан реальных каталогов для измерений допустим только в режиме чтения; не сохраняй содержимое чужих путей в репозиторий, devlog, скриншоты и фикстуры. В отчётах используй агрегаты и синтетические имена.
- Не включай автоматическое удаление «по умолчанию» ни в UI, ни в CLI, ни в MCP. MCP-инструменты с деструктивным эффектом помечаются `destructive: true` и требуют `confirm`.
- Перед любым действием, которое нельзя откатить (безвозвратное удаление, форматирование, запись в системные каталоги), останавливайся и спрашивай человека.

## Права и привилегии

- Быстрый MFT-путь требует прав администратора. Приложение не повышает привилегии молча: показывает запрос, при отказе откатывается на переносимый путь. Тесты с админ-правами — `#[ignore]`.
- Приложение не отправляет данные о файлах по сети. Телеметрии нет. Любая сетевая функция — отдельное решение человека и ADR.

## Приватность в логах

Пути пользователя в логах — только на уровне `debug` и не в релизных сборках по умолчанию. Скриншоты и отчёты для публикации — на синтетических данных.
