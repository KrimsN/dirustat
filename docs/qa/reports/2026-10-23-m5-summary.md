## What held up

- Export path validation (system folders, wrong extension, inside the scanned tree including a junction, UNC, existing file, device names, ADS), no leftover temp files, CSV formula guard.
- 46 hand-built hostile snapshots with a valid checksum and about 1,700 mutated files were refused without a panic; a snapshot round trip is byte-identical in JSON and CSV exports.
- Every destructive command is `not_enabled` while a snapshot is shown, by path and by id.
- `treemap.look` and `settings.set` reject NaN, infinity and out-of-range values; hand-edited settings are clamped.
- Duplicate search cancel (6 GB hash stops within one poll), paging, closing and quitting during a run; UI stays responsive during long jobs.

## Coverage gaps

- No mouse input reached the app: menus (File > Export, Snapshot, View, Tools), shortcuts, slider dragging, hover tooltips, hit-testing in the map next to the free-space band, the Compare result list and the native dialogs were not tested.
- `export.png` only through the desktop app (headless is `unsupported`); no PNG visual review beyond QA-251.
- TCP control server under concurrent commands, MFT fast path, fuzz targets, performance budgets on 1M nodes, hand-edited settings through the real app start-up path.
