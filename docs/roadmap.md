## Критерии выхода

- **M1:** `cargo run -p dirustat` открывает окно, скан тестовой папки отображается деревом и treemap, выбор синхронизирован, UI не блокируется, `cargo xtask ci` зелёный, скриншот приложен в devlog, скан 1M синтетических файлов измерен.
- **M2:** все команды вызываются из UI, CLI, control и MCP; hostile-тест зелёный; агент снимает скриншот через `ui.screenshot`.
- **M3:** скан 1M файлов MFT ≤ 3 с (замер в devlog); без прав — прозрачный откат; fuzz MFT-парсера без падений.
- **M4:** деструктивные команды удовлетворяют `docs/safety.md`, тесты на отказ.
- **M5:** cushion в бюджете кадра; снимки сохраняются/сравниваются.
- **M6:** CI зелёный на Windows/Linux/macOS, релиз собирается автоматически.
- **M7:** локализации ru/en, чеклист доступности.
